Un wrapper TUI simple para el cliente CLI oficial de NordVPN.

## Instalación y uso

```bash
git clone https://github.com/bosinnfan/bad-nordvpn-tui-wrapper
cd bad-nordvpn-tui-wrapper/nordtui 
cargo build --release
chmod +x target/release/nordtui
sudo cp target/release/nordtui /usr/local/bin/

```

## Requisitos

* Rust / Cargo
* Cliente CLI oficial de NordVPN instalado y configurado
